# 財布アプリをiPhoneのホーム画面に入れる手順

必要なもの：Windowsのブラウザと、iPhone。インストールするソフトはありません。費用もかかりません。

ファイルは6つです。**すべて同じ場所に、ファイル名を変えずに**置いてください。

- `index.html` … アプリ本体
- `manifest.webmanifest` … アプリ名やアイコンの設定
- `sw.js` … オフラインで動かすための仕組み
- `apple-touch-icon.png` … ホーム画面のアイコン（iPhone用）
- `icon-192.png` / `icon-512.png` … アイコン（Android・その他用）

---

## 1. GitHubにアカウントを作る（初回のみ・5分）

1. Windowsのブラウザで https://github.com を開く
2. 「Sign up」からメールアドレス・パスワード・ユーザー名を登録
3. 届いたメールの数字を入力して認証

ユーザー名は公開URLの一部になります。短めの英数字がおすすめです。

## 2. 置き場所（リポジトリ）を作る

1. 右上の「＋」→「New repository」
2. Repository name に `kakeibo` と入力
3. **Public** を選ぶ（Privateだと次のGitHub Pagesが使えません）
4. 「Create repository」

> Publicなので、URLを知っている人は誰でもこのページを開けます。ただし**あなたの家計データはiPhoneの中だけに保存され、インターネットには一切送られません**。公開されるのはアプリの画面だけです。

## 3. ファイルをアップロードする

1. 作られたページの「uploading an existing file」（または Add file → Upload files）をクリック
2. 6つのファイルをまとめてドラッグ&ドロップ
3. 下の「Commit changes」をクリック

## 4. 公開する（GitHub Pages）

1. 上部メニューの「Settings」→ 左メニューの「Pages」
2. Source が「Deploy from a branch」になっていることを確認
3. Branch を `main`、フォルダを `/ (root)` にして「Save」
4. 1〜3分待ってページを再読み込みすると、上部にURLが表示されます

```
https://（あなたのユーザー名）.github.io/kakeibo/
```

## 5. iPhoneのホーム画面に追加する

1. **Safari**でそのURLを開く（Chromeではホーム画面に追加できません）
2. 下部中央の共有ボタン（□に↑）をタップ
3. メニューを下にスクロールして「ホーム画面に追加」
4. 名前を確認して「追加」

これで完了です。アイコンをタップすると、Safariのアドレスバーがない全画面でアプリとして起動します。機内モードでも動きます。

---

## 21時のリマインドを確実にする（iPhoneの設定）

アプリ内の設定でリマインドをオンにすると、アプリを開いたときに「今日はまだ記録がありません」と表示されます。ただしiPhoneでは、**アプリを閉じている間に音を鳴らすことはできません**。毎晩確実に気づくには、iPhone標準の「ショートカット」アプリを使います。

1. 「ショートカット」アプリ →「オートメーション」タブ →「＋」
2. 「時刻」を選び、21:00・毎日に設定 →「次へ」
3. 「新規の空のオートメーション」→ アクションを追加 → 「Appを開く」
4. ホーム画面に追加した「財布」を選ぶ
5. 「すぐに実行」をオンにして完了

これで毎晩21時に自動でアプリが開き、記録していなければお知らせが出ます。

---

## データのバックアップ

記録はiPhoneの中だけに保存されます。**Safariの履歴やWebサイトデータを消すと、記録も消えます。**

月に一度、設定タブの「書き出す」を押してバックアップファイルを保存してください（「ファイル」アプリやiCloud Driveに保存できます）。機種変更や復元のときは「読み込む」から同じファイルを選べば元に戻ります。

## アプリを直したくなったら

このチャットで修正した `index.html` をもらって、GitHubの同じファイルを差し替えるだけです（ファイルをクリック → 鉛筆アイコン → 中身を貼り替え → Commit）。中身を更新したときは `sw.js` の1行目付近にある `wallet-v1` を `wallet-v2` のように数字を1つ上げると、iPhone側が確実に新しい版を読み込みます。
